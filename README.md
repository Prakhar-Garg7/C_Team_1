Aim: A zero-dependency digital image processing engine implementing custom 2D convolution, Gaussian/Median blurring, Laplacian edge detection, and Unsharp Masking directly on raw pixel matrices.

How to run?
1. Install requirements from requirements.txt. Command: pip install -r requirements.txt
2. Run app.py. Command: python -m streamlit run app.py

Project deploy link: https://cteam1-ipcvproj.streamlit.app/
